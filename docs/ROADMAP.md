# Roadmap / 路线图

| Phase | 内容 | 状态 |
|---|---|---|
| 0 | 仓库底座：MIT、CI、gitleaks、合规文档、合成数据 | ✅ |
| 1 | 最小运维：健康检查、告警（面板+Webhook）、加密凭据库（轮换/到期提醒/脱敏）、备份恢复、审计、配置中心 schema、安全清理 | ✅ |
| 2 | 合成数据演示站（libSQL/Turso HTTP 路径、FTS 方言、卡片/标签/画师/复制提示词、Key+额度 API）；TS Cloudflare Worker 已完成（与 Python 参考实现逐字节一致） | ✅ |
| 3 | FastAPI + React 面板：包任务看板、清理预览+确认、统一状态页+事件日志、告警确认（仅本机） | ✅（尚未接入生产 runner） |
| 4 | 合规爬虫 MVP：适配器插件、robots/限速/诚实 UA/跳过登录付费墙、出处+许可、元数据默认、去重、断点续爬、site-pack-v1、端到端测试 | ✅ |
| 5 | 存储路由（本地/S3 兼容/内存，故障切换）、热冷迁移（先校验后删除）、用量采样与触顶预测、成本看板+告警 | ✅（真实 R2/S3 仅用假客户端测试） |
| 6 | 邀请制用户、配置中心面板、回滚、安全自检、白皮书 | ✅ (发布目标为本地模拟 / local simulated release target) |
| 7 | 与生产 pack 契约对齐（预约窗口） | ⏳ |
